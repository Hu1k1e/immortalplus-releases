# Security and privacy reports

If you think the app does something it should not (reads more than the Dota 2 window, sends data it should not, writes files it should not),
please tell us before making it public: use this repository's **Security** tab and choose **Report a vulnerability**. That report is private.

Please include what you saw, how to reproduce it, and the app version.

In scope: the code in this repository and the Windows app's behaviour on your PC.
